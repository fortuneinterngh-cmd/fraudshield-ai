ℹAbout this build

FraudShield AI is a human-layer fraud detection system for Ghana's MoMo ecosystem. MTN's backend risk systems score transactions; awareness campaigns warn before the scam begins. The scam itself happens between them — at the moment of manipulation — where no defense currently operates. FraudShield inserts defense at exactly that moment.

All models run locally: no server, no tracking, no data leaving the device. Zero external dependencies means the demo cannot fail offline.

Built for: MoMo Fintech Lab — Build with MoMo, Track 3: Trust, Security & Digital Identity.
